Pre-production and production for a containerised search engine, without Kubernetes

I built, as code, the pre-production and production environments for a search engine (index, dashboard, API) on Docker hosts, with no Kubernetes cluster. Both environments were delivered in April 2026, and the setup was reused for a second search engine.

Period
February to April 2026; adjustments until July 2026
My role
Initiator, later taken over by others

Sole author of the operations project when it was created, later taken over by others. The application is developed by another team.

Context

A development team was building a search engine: an index, a dashboard and a Python API. They initially planned to run it on Kubernetes. They needed a pre-production and a production environment.

What I did

  1. After a scoping meeting with the development team, I defined and documented an architecture on Docker hosts: proxy, search index and dashboard in containers, Python API, log and metrics collection.
  2. I created the pre-production and production machines with Terraform.
  3. I wrote the initial Ansible project: Docker and the proxy, the containerised search index with its certificates, security configuration and encrypted secrets, the dashboard and the Python API.
  4. I set up blue/green deployment for the API (new instance, health check, traffic switch, old instance removed) with a job for developers.
  5. I connected the logs to the central logging chain with a dedicated dashboard, and collected metrics from the system, processes, containers, proxy and application server.
  6. I wrote version 1.0 of the architecture document for the hosting provider (deployment, upgrade, rollback), installed the security agent and added the firewall rules for the exposed zone.
  7. I gave the development team read access to the project's secrets stored in the job scheduler.

Technologies

  • Terraform
  • Ansible
  • Docker
  • OpenSearch
  • OpenSearch Dashboards
  • nginx
  • Python (uWSGI)
  • Filebeat
  • ELK
  • Prometheus
  • cAdvisor
  • Rundeck

Result

Both environments were delivered in April 2026.

What happened next

The setup was reused for a second search engine: I created the project and broke down the work, and a colleague carried it on. After the development team's test feedback, I fixed the permissions of two index roles there. The original operations project was later taken over by others.
